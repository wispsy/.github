## Wispsy — an independent Python ecosystem

Small, independently useful tools. Explicit contracts. Larger ideas through composition.

Wispsy develops Python foundations, composition libraries, frameworks, runtimes and applications. Each project owns its public interface and release lifecycle. Integration is intentional, not mandatory.

### Explore the ecosystem

| Layer | Purpose | Examples |
| --- | --- | --- |
| **Foundation** | Parsing, transport, types, data and storage | `astree`, `requ`, `enforce_type`, `backpack` |
| **Composition** | Capabilities, workflows and application assembly | `hidden_moves`, `moveset`, `scriptty` |
| **Framework** | Interfaces, services and runtimes | `expose_api`, `carets`, `spatial_ui`, `pocket-python` |
| **Application** | Useful software built from these ideas | `pretty-notebook`, `peaches`, `clownfish` |
| **Tooling** | Development, packaging and distribution | `evok`, `shimify`, `immunity` |
